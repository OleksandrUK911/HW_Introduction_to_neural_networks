## 🧮 Математичні основи

### Функція гіпотези

$$\hat{y} = \sigma(x W^T + b) = \frac{1}{1 + e^{-(x W^T + b)}}$$

### Сигмоїдна функція

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

### Функція втрат (бінарна крос-ентропія)

$$L(y, \hat{y}) = - \left[ y \cdot \log(\hat{y}) + (1 - y) \cdot \log(1 - \hat{y}) \right]$$

## 🔑 Ключові висновки

### 1. Проблема зникнення градієнтів

Проєкт практично демонструє проблему **gradient vanishing**, яка виникає, коли:
- Ваги ініціалізовані великими випадковими значеннями
- Сигмоїдна функція переходить у стан насичення (значення близькі до 0 або 1)
- Градієнти стають дуже малими або нульовими
- Навчання моделі зупиняється

**Рішення:** Ініціалізація ваг малими значеннями навколо нуля.

### 2. Важливість правильної ініціалізації

Правильна ініціалізація параметрів є критичною для успішного навчання. У проєкті показано:
- Негативний ефект великих початкових ваг
- Позитивний результат малих ваг (поділ на 1000)

### 3. Листові тензори (Leaf Tensors)

Використання `.data` для in-place операцій забезпечує:
- Збереження тензорів як листових
- Коректне накопичення градієнтів
- Правильну роботу автоматичного диференціювання

### 4. Порівняння підходів
